# Aura Estate

Демо-лендинг вымышленного агентства недвижимости. Чистый HTML, CSS и JS без сборки: Vercel отдаёт корень репозитория как статику.

## Запуск

```bash
py -3.13 -m http.server 8123
```

Открыть `http://127.0.0.1:8123/`. Через `file://` браузер может заблокировать локальные шрифты.

## Структура

```
index.html          разметка и инлайн-план квартиры
style.css           токены, поверхности, компоненты, адаптив
script.js           меню, появление блоков, GSAP-анимация hero, магнитная кнопка, форма
assets/fonts/       Prata, Golos Text, Martian Mono (woff2, OFL)
assets/favicon.svg
pics/               скриншоты проверки, в git не входят
```

## Дизайн-система

Пресет «Индекс» (APM): белая бумага, чёрные секции, розовый акцент. Секции объявляют поверхность `surface-paper`, `surface-mist`, `surface-ink` или `surface-accent` и переопределяют `--bg`, `--fg`, `--fg-muted`, `--hairline`, `--plate`, `--focus`, `--btn-*`. Компоненты читают только эти переменные.

Палитра: `#FFFFFF`, `#000000`, `#0B0B0B`, `#686868`, `#9A9A9A`, `#E2E2E2`, `#F3F3F3`, `#F06793`, `#B8245A`. Розовый текстом на белом не используется, для текста есть малиновый `#B8245A` (6,1:1). Белый текст на розовом не используется.

Шрифты: Prata (дисплей), Golos Text (текст), Martian Mono (цифры и мета). Все три с кириллицей, лежат локально, fallback-метрики подобраны через `size-adjust` и `ascent-override`.

Отпечаток: план квартиры как портрет объекта. Кольца ауры собраны в знак, розовая точка отмечает объект в плане и стоит в подвале.

## Демо-данные

Название, адрес, телефон, почта, цены, метрики и объект в каталоге вымышлены. Форма проверяет поля и показывает состояние успеха, но заявку никуда не отправляет: бэкенда нет. Для продакшена нужно подключить endpoint и серверную валидацию.

## Проверено

- 1440, 1024, 768 и 390 px: `scrollWidth` равен `innerWidth`, горизонтального скролла нет.
- `document.fonts.check` для Prata, Golos Text и Martian Mono возвращает `true`.
- `prefers-reduced-motion: reduce` отключает движение, контент остаётся видимым.
- GSAP 3.12.5 + ScrollTrigger с CDN: вход заголовка hero (сдвиг + opacity) и параллакс плана; при reduced motion твины не запускаются.
- Без JS заголовок и блоки видны: скрытие включает только класс `js`.
- Форма: пустая отправка показывает три ошибки и ставит фокус в первое поле; валидная показывает экран успеха.
- Меню и диалог политики: `inert`, `aria-expanded`, возврат фокуса, Escape.

## Деплой

GitHub Pages: ветка `main`, папка `/` (root). Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`. Адрес: https://winteri9.github.io/aura-estate/. Сборка не нужна, `index.html` лежит в корне, `.nojekyll` отключает Jekyll.
